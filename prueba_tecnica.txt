Prueba Técnica Frontend: Landing Page 
+ Firebase 
Objetivo 
El objetivo de esta prueba es evaluar tus habilidades en HTML, CSS y JavaScript, así 
como tu capacidad para traducir un diseño de Figma a código funcional, integrando 
servicios de Firebase para el almacenamiento de datos y el despliegue del proyecto. 
Stack Tecnológico Requerido 
● Frontend: HTML5, CSS3, JavaScript (Vanilla / ES6+). 
● Backend / BaaS: Firebase (Firestore / Realtime Database). 
● Hosting: Firebase Hosting. 
● Control de versiones: Git / GitHub (o GitLab/Bitbucket). 
Requerimientos de la Prueba 
1. Maquetación y Diseño (Figma) 
● Construye la estructura de la landing page basándote en el diseño proporcionado: 
https://www.figma.com/design/FAZhLOJkpBlQcMPbwEKCH6/Prueba-Ingreso
Obvio-Latam?node-id=2482-17944&p=f&t=hwJtWtJ8GsAIFPQf-0. 
● Fidelidad de diseño: Respeta los colores, tipografías, espaciados y disposición de 
elementos. 
● Responsividad: La interfaz debe adaptarse correctamente a dispositivos móviles, 
tablets y escritorio. 
2. Funcionalidad y Formulario 
● Implementa la lógica del formulario de contacto/captura con JavaScript. 
● Validación: El formulario debe validar en el cliente que los campos requeridos no 
estén vacíos y que los formatos (por ejemplo, el correo electrónico) sean válidos 
antes de enviar. 
● Feedback al usuario: Muestra mensajes visuales claros al usuario en caso de error 
o cuando la información se haya enviado con éxito. 
3. Integración con Firebase 
● Base de datos: Conecta el formulario a Firebase Firestore (o Realtime Database) 
para almacenar las entradas del formulario en tiempo real. 
● Hosting: Despliega la aplicación utilizando Firebase Hosting. 
Entregables 
Para dar por completada la prueba, deberás enviar los siguientes elementos: 
1. Enlace al repositorio público (GitHub, GitLab, etc.) con el código fuente. 
○ Incluye un archivo README.md explicativo con las instrucciones para 
ejecutar el proyecto localmente y los detalles relevantes de tu solución. 
2. Enlace a la landing page en vivo desplegada en Firebase Hosting (ejemplo: 
tu-proyecto.web.app). 
Criterios de Evaluación 
Criterio Descripción 
Fidelidad visual Qué tan fiel es el resultado final respecto al diseño entregado 
en Figma. 
Calidad de código Código semántico, limpio, organizado, modular y fácil de 
mantener. 
Responsividad Correcta adaptación del sitio en distintas resoluciones de 
pantalla. 
Funcionalidad Validación efectiva del formulario y correcto guardado de 
datos en Firebase. 
Despliegue Correcta configuración e integración con Firebase Hosting. 
Uso de Git Historial de commits claro, descriptivo y progresivo.
